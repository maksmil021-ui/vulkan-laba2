# Лабораторная работа №2 по компьютерной графике (Vulkan)

**Вариант 10:** Правильный додекаэдр

## Описание
Программа на C++ с использованием API Vulkan для отрисовки 3D-модели правильного додекаэдра с динамическим освещением и управляемой камерой в реальном времени.

**Реализовано (базовое задание на оценку 3):**
- Управляемая камера (позиция в пространстве и угол обзора FOV).
- Один направленный источник света (Directional Light) с настройкой направления, цвета и интенсивности.
- Освещение по модели Блинн-Фонга (Ambient + Diffuse + Specular) во фрагментном шейдере.
- Управление параметрами материала через ImGui: альбедо (базовый цвет), цвет блика и коэффициент блеска (Shininess).
- Процедурная генерация нормалей вершин для корректного расчета освещения.
- Отрисовка закрашенных граней с черными ребрами (Wireframe) с помощью двух графических конвейеров.

## Сборка и запуск
**Требования:** Vulkan SDK, CMake (3.20+), компилятор C++20.
1. Склонируйте репозиторий.
2. Сгенерируйте проект через CMake (зависимости GLFW, GLM, ImGui, VMA скачаются автоматически).
3. Соберите проект и запустите `vulkan-laba2.exe`.
